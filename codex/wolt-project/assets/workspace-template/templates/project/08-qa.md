# Preflight QA

## Creative & production

- [ ] First frame ясно читается в thumbnail size.
- [ ] Hook полностью работает в 0–3s.
- [ ] Wolt bag/logo появляется в 0–3s, если это не ослабляет идею; иначе художественная причина записана.
- [ ] Одна dominant idea, cause-and-effect и payoff без explanatory text.
- [ ] Main action/reveal завершён к 6s; 6–15s имеют функцию.
- [ ] Все beats покрывают 0–15 без gaps/overlaps.
- [ ] Performance описан playable actions, positions, eyelines и contacts.
- [ ] Camera moves motivated, spatially coherent, one dominant move per shot.
- [ ] На каждой обычной склейке крупность обычно меняется минимум через одну ступень и угол/высота/ось — заметно; исключения мотивированы искусством и не выглядят accidental jump cut.
- [ ] Light задаёт source, direction, quality, contrast/color и exposure priority.
- [ ] Cuts complementary; action phase, eye trace, screen direction и object count сохранены.
- [ ] Sound синхронизирован с видимыми contacts/transitions.
- [ ] Soundtrack использует instrumental music + SFX/Foley; нет dialogue/VO/spoken words/vocals/lyrics без explicit request.
- [ ] Нет infographic, charts, diagrams, arrows, UI panels, callouts, labels или explanatory overlays без explicit request.
- [ ] Exact final frame readable и оставляет clean post-copy space.

## Wolt compliance

- [ ] Hero bag сохраняет geometry/material/print/logo и является единственным branded object.
- [ ] Остальная упаковка generic, textless, unbranded.
- [ ] Нет generated copy, CTA, prices, claims, legal, watermarks или extra typography.
- [ ] Нет pork, alcohol/context, meat+dairy, molluscs/shellfish или ambiguous food.
- [ ] Burger/pizza, sauces, bag contents, final pack shot и все background foods названы безопасно; нет pepperoni/cheeseburgers, молочных соусов/сыра/масла с мясом.
- [ ] Pharmacy rules/approvals учтены, если применимо.

## Reference control

- [ ] Каждый asset классифицирован и имеет narrow job + exclusions.
- [ ] Attach order совпадает с реальными файлами.
- [ ] Existing storyboard используется как `@Image1`; replacement не создан без запроса.
- [ ] Нет phantom tags.
- [ ] Bag/courier refs не управляют лишними свойствами.
- [ ] Если есть courier, все storyboard/video кадры framed below chin: no face/eyes/mouth/full chin/identity; crop выглядит естественно.

## Prompt contract

- [ ] Один complete prompt на весь spot.
- [ ] English prompt standalone и полон; RU Client Story — только краткое описание.
- [ ] Один fenced video block по умолчанию; второй ZH — только по запросу.
- [ ] Если ZH запрошен: естественный язык, те же time ranges, counts, references, restrictions и final state, что в текущем EN.
- [ ] Включены только 3–7 relevant failure protections.

## Client approval gate

- [ ] Клиент видел актуальные storyboard + short scenario.
- [ ] Все замечания записаны и закрыты версиями.
- [ ] `APPROVED_FOR_GENERATION: YES` имеет date/source evidence.
- [ ] Approved scenario/storyboard/video-prompt versions совпадают с generation inputs.

## Storyboard render gate

- [ ] Обычный text package не запускал image generation.
- [ ] Render выполнен только после explicit user request.
- [ ] Использованы точные current storyboard prompt version и asset list.
- [ ] Концепция не была молча изменена во время рендера.

## Generation & delivery

- [ ] Exact attach list соответствует реальным файлам; обычно approved storyboard + Wolt bag.
- [ ] Approved master выбран и записан до upscale.
- [ ] 4K — отдельный upscale до 3840×2160, без native Seedance 4K claim.
- [ ] Upscale QA пройден на 100%: logo/print, kraft texture, faces/hands, food, flicker/halos/banding, audio sync.
- [ ] Final encode соответствует client delivery spec.
- [ ] После результата заполнен `09-retrospective.md`; idea outcome не объявлен успешным/неуспешным без evidence.
